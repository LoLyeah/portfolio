**DataSight** is a clean, interactive web application designed to simplify data exploration and visualization. It provides developers and analysts with an elegant, responsive interface to load datasets, filter entries, and generate beautiful visual reports.

### Key Features
- **Interactive Dashboards:** Custom charts and graphs built using modern, lightweight rendering.
- **Fast Filtering:** Perform complex queries on tabular data instantly on the client side.
- **Responsive Layout:** Responsive and accessible UI tailored to any screen size.
- **TypeScript Core:** Solid type safety and highly optimized data pipelines.
