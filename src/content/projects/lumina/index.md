**Lumina** is an aesthetic design toolkit and component system focusing on modern glassmorphism, rich gradients, and smooth interactive states. It provides developers with highly responsive, beautiful elements to elevate their web apps instantly.

### Key Features
- **Vibrant Glassmorphism:** Rich backdrop-filter backdrops with subtle borders and HSL gradient overlays.
- **Micro-Animations:** Fluid, interactive states for buttons, inputs, and navigations.
- **Dual Aesthetic Support:** Sleek, fully customized light and dark modes that transition seamlessly.
- **Easy Integration:** Ready-to-use utility classes and components designed to align perfectly.
