**MedQuiz** is an educational frontend application that offers medical students, professionals, and enthusiasts a gamified interface to test their clinical knowledge. 

### Key Features
- **Dynamic Question Sets:** A robust database of medical scenarios and multiple-choice questions.
- **Detailed Explanations:** Instantly review full explanations and anatomical references for each answer.
- **Progress Tracking:** Analyze your performance over time with visual stats and progress cards.
- **Modern Polish:** Minimalist layout featuring smooth transitions, beautiful typographic hierarchy, and responsive dark mode.
